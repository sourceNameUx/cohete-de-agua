# Cohete de Agua — Proyecto de ciencias

Página web de una sola vista para el proyecto de física del **cohete de agua**.
Incluye:

- Explicación de cómo funciona el cohete y las leyes físicas que intervienen.
- **Simulador interactivo** (agua, presión, ángulo) con resultados y gráfica.
- Partes del cohete, guía de construcción paso a paso y reglas de seguridad.
- Galería de fotos con visor ampliado, mediciones, glosario, quiz y equipo.

La página es autocontenida: estilos, scripts y fotos (en base64) viven dentro del
HTML, así que funciona sin servidor ni dependencias locales. Solo carga las
tipografías desde Google Fonts.
